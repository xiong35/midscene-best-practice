# 懂车帝 APP context

## 首页

- 上半部分金刚位有排行榜 icon，点击跳转到排行榜页面。
- 中间有搜索框，点击进入搜索页面。
- 下半部分有帖子瀑布流，可无限滚动。
- 底部有 fixed tab，分别有首页、选车、AI、消息、我的 Tab，点击进入对应页面。

## 排行榜页面

- 上半部分可选择销量榜等榜单。
- 中部可选择 filter。
- 下方是在榜车型 list，会展示排名和车型名称，点击车型进入详情页。

## 车型详情页面

- 页面会展示车型名称。
- 页面右上角有心形关注按钮，可以关注或取消关注当前车型。

## 我的页面

- 顶部有用户信息。
- 中间有关注订阅、收藏按钮，点击进入对应页面。
- 下方有所有功能列表。
- 更下方不可见处有精彩活动列表。
- 底部有 fixed tab，分别有首页、选车、AI、消息、我的 Tab，点击进入对应页面。

## 关注订阅页面

- 关注 Tab 下可在用户和汽车之间切换。
- 汽车列表会展示已经关注的车型。
